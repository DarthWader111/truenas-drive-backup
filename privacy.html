Privacy Policy

Last updated: November 4, 2026

About this application

TrueNAS Drive Backup is a personal, non-commercial application used by its owner to synchronize files between a personal TrueNAS SCALE server and Google Drive.

Google Drive access

The application accesses Google Drive only with authorization from the Google account owner.

Access is used to upload, list, update, and manage backup files in the owner's Google Drive account.

Data storage

Files are transferred directly between the owner's TrueNAS server and Google Drive. This website does not receive or store the contents of those files.

OAuth credentials are stored in the owner's TrueNAS configuration and are not published on this website.

Data sharing

The application does not sell user data or share Google account information with third parties for advertising or marketing.

Data control

The owner can revoke Google Drive access through Google Account security settings and remove backup files directly from Google Drive.

Contact

For privacy questions, contact the application owner through the public GitHub repository.
